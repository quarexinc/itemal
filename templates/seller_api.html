Kullanım

Tüm isteklerde Authorization: Bearer <anahtar> başlığı gerekir. Dakikada en fazla 120 istek gönderebilirsin. Yanıtlar JSON'dur.

Profil ve bakiye

curl {{ base }}/api/v1/me \
  -H "Authorization: Bearer itm_..."

İlanlarını listele

curl {{ base }}/api/v1/listings \
  -H "Authorization: Bearer itm_..."

Stoğa kod ekle

curl -X POST {{ base }}/api/v1/listings/12/stock \
  -H "Authorization: Bearer itm_..." \
  -H "Content-Type: application/json" \
  -d '{"codes": ["ABCD-1234", "EFGH-5678"]}'

İlanı duraklat / yayınla

curl -X POST {{ base }}/api/v1/listings/12/status \
  -H "Authorization: Bearer itm_..." \
  -H "Content-Type: application/json" \
  -d '{"status": "paused"}'

Satışları çek

curl "{{ base }}/api/v1/orders?after_id=0&limit=50" \
  -H "Authorization: Bearer itm_..."

Satış yanıtlarında alıcıya teslim edilen kodlar yer almaz.
